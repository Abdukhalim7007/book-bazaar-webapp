# BookBazaar Backend

## O‘rnatish

```bash
pip3 install -r requirements.txt
```

(Agar `pip3` topilmasa: `python3 -m pip install -r requirements.txt`)

## Ishga tushirish

```bash
python3 -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

- API: http://localhost:8000
- Docs: http://localhost:8000/docs
